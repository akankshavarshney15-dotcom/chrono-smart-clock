## 📖 About The Project

**Chrono – Smart Clock** is a modern, interactive and user-friendly web application designed to make time management simple and efficient.

It combines multiple time-related utilities into a single dashboard, allowing users to check real-time information, manage alarms, measure elapsed time, set countdowns and view the current time across different countries.

The application features a modern blue-themed interface, interactive components and a dark/light mode for a comfortable user experience.

## ✨ Key Features

### 🕒 Digital Clock
- Displays real-time hours, minutes and seconds.
- Shows the current date and day.
- Automatically updates every second.

### 🕰️ Analog Clock
- Interactive analog clock interface.
- Moving hour, minute and second hands.
- Real-time synchronization.

### ⏰ Alarm Manager
- Set multiple alarms.
- Add custom alarm labels.
- Select from built-in alarm tunes.
- Preview alarm sounds before setting.
- Enable, disable and delete alarms.
- Stop active alarms.

### ⏱️ Stopwatch
- Start, pause and reset functionality.
- Record multiple lap times.
- Displays elapsed time with milliseconds.

### ⏳ Countdown Timer
- Set custom hours, minutes and seconds.
- Start, pause and reset controls.
- Displays countdown in real time.
- Completion notification.

### 🌍 World Clock
- Displays current time in different countries.
- Includes India, USA, UK and Japan.
- Uses international time-zone conversion.
- Automatically updates every second.

### 🎨 Additional Features
- Modern blue-themed dashboard.
- Dark and light mode.
- Local Storage for saving alarms and theme preferences.
- Interactive navigation.
- Clean and user-friendly interface.

## 🚀 Getting Started

Follow these instructions to run the project on your local machine.

### Prerequisites

- A modern web browser.
- Visual Studio Code.
- Live Server extension (recommended).

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd chrono-smart-clock
```

**3. Open the project in Visual Studio Code**

```bash
code .
```

**4. Run the application**

Open `index.html` using the Live Server extension or open it directly in your browser.
